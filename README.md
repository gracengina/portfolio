## Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/gracengina/portfolio.git
```

### 2. Open the project folder

```bash
cd portfolio
```

### 3. Run the website

Open `index.html` directly in a browser

or

Use VS Code Live Server:

* Install Live Server extension
* Right-click `index.html`
* Select "Open with Live Server"

---

## Deployment

### Deploy using GitHub Pages

1. Open the repository on GitHub
2. Go to **Settings → Pages**
3. Under **Source**, choose:

   * Branch: `main`
   * Folder: `/root`
4. Save changes

The site will be available at:

```
https://gracengina.github.io/portfolio
```

Allow a few minutes for the first deployment.

---

### Alternative Deployment (Netlify)

1. Go to Netlify
2. Select **Add new site → Import from Git**
3. Choose your `portfolio` repository
4. Deploy (no build command required for static sites)
